# HakolSlides

PowerPoint inside Resolume Arena: slides, presenter view and notes, exactly as PowerPoint shows them.

**Download:** [HakolSlides.dmg](https://github.com/omz-commits/hakolslides-releases/releases/latest/download/HakolSlides.dmg)
